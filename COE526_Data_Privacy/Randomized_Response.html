The raw inversion is an unbiased estimate and may fall below 0% or above 100% in a small sample. The feasible value is clipped only for display. The 95% interval transforms a Wilson interval for the observed Yes proportion and then clips its endpoints to the feasible 0%–100% range.
Key comparison: Stations 1 and 3 use different procedures but produce the same channel: P(report Yes | true Yes) = 0.75 and P(report Yes | true No) = 0.25. They therefore have the same reconstruction formula and ε. The die reports the truthful value with probability 5/6, so it provides more statistical signal but weaker privacy because ln(5) > ln(3). All stations use the same question so their results can be compared without changing the underlying survey item.

📈 Mathematical Proofs of Reconstruction

Station 1 (Coin: Two-Coin Forced Response) P(Y=Yes | X=Yes)=0.75; P(Y=Yes | X=No)=0.25 P(Y=Yes) = 0.5π + 0.25 Inversion: π̂ = 2 × (P̂ - 0.25) Privacy: ε = ln(0.75 / 0.25) = ln(3) ≈ 1.10
Station 2 (Die: Die-Based Forced Response) P(Y=Yes | X=Yes)=5/6; P(Y=Yes | X=No)=1/6 P(Y=Yes) = (4/6)π + 1/6 Inversion: π̂ = (6P̂ - 1) / 4 Privacy: ε = ln((5/6) / (1/6)) = ln(5) ≈ 1.61
Station 3 (Spinner: Warner Complementary Question) P(Y=Yes | X=Yes)=0.75; P(Y=Yes | X=No)=0.25 P(Y=Yes) = 0.75π + 0.25(1-π) = 0.5π + 0.25 Inversion: π̂ = 2 × (P̂ - 0.25) Privacy: ε = ln(0.75 / 0.25) = ln(3) ≈ 1.10
